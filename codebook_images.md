# Codebook: Generated Images — Visual Analysis

This codebook is applied to photorealistic images generated by participants during a workshop on loneliness. Each image was produced by Gemini in response to a participant-written prompt. The codebook is designed to capture what is visually present in the image itself, independent of the prompt that produced it. All codes are binary (1 = present, 0 = absent) and non-mutually exclusive unless noted.

The codebook is organised into four sections: (A) setting and environment, (B) social configuration, (C) visual cues for loneliness, and (D) AI default tropes. A fifth section (E) captures the overall adequacy of the image relative to common prompt intentions.

---

## A. Setting and Environment

### Code 1: Indoor domestic setting
The image is set inside a home — bedroom, kitchen, living room, or similar private space.

### Code 2: Public or institutional setting
The image is set in a public or semi-public space — café, library, canteen, classroom, corridor, transport, or similar.

### Code 3: Outdoor setting
The image is set outdoors — street, park, campus grounds, or natural environment.

### Code 4: Darkness or dim lighting
The scene uses low light, shadows, night-time, or visibly dim/grey conditions as a dominant atmospheric feature. **Mutually exclusive with Code 5** — apply whichever describes the dominant lighting condition. If the scene is generally bright but has a dim corner, code by the dominant atmosphere. When in doubt, code 0.

### Code 5: Bright or neutral lighting
The scene is lit normally — daylight, indoor artificial light, or bright conditions with no notable atmospheric darkness. **Mutually exclusive with Code 4.**

---

## B. Social Configuration

### Code 6: Subject is physically alone
**Descriptive.** The subject is the only person in the scene. Code based on visible scene composition only — no inference about emotional state required. Code 0 if others are present and nearby, even if the subject is not interacting with them.

### Code 7: Subject is in a group or crowd
The subject is visibly surrounded by or in proximity to other people (two or more others present and nearby).

### Code 8: Others are visibly engaged with each other
Other people in the scene are shown interacting, talking, laughing, or connecting — in contrast to the subject.

### Code 9: Subject is visibly excluded or peripheral
**Descriptive.** The subject's spatial position or body orientation signals exclusion — seated at the edge of a group, back turned to others, facing away, or physically marginal in the frame. Code based on visible spatial and postural cues only; do not infer exclusion from facial expression alone. Distinguish from Code 6: Code 6 = subject is alone in the scene; Code 9 = subject is present with others but spatially or posturally marginalised.

---

## C. Visual Cues for Loneliness

### Code 10: Sad or distressed facial expression
The subject's face shows visible sadness, distress, blankness, or emotional pain. Code 1 only when specific visible anchors are present: tears or tear-streaked cheeks, visibly downturned mouth or pronounced frown, furrowed brow, clenched jaw, trembling lip, red or puffy eyes, or a vacant unfocused stare. Do not apply for neutral or ambiguous expressions, or for subtle microexpressions that require inference. When in doubt, code 0.

### Code 11: Withdrawn body language
The subject's posture signals withdrawal or disconnection — hunched shoulders, arms crossed, head down, slumped, curled inward.

### Code 12: Downward or averted gaze
The subject is looking down, away, out a window, or otherwise not engaging visually with the environment or others.

### Code 13: Technology or screen use
A phone, laptop, or screen is a visible focal element, used by the subject in a context that signals isolation from others.

### Code 14: Loneliness conveyed through physical isolation
**Interpretive summary — mutually exclusive with Code 15.** The image primarily conveys loneliness through the subject being alone in a space; the physical absence of others is the dominant loneliness signal. Apply only when Code 6 = 1 and there are no others present to create social contrast. If others are present, use Code 15 instead.

### Code 15: Loneliness conveyed through social disconnection
**Interpretive summary — mutually exclusive with Code 14.** The image primarily conveys loneliness through the subject being present with others but visibly disconnected — social exclusion or invisibility is the dominant loneliness signal. Apply only when Code 7 = 1 (others present). If the subject is alone with no others in the scene, use Code 14 instead.

*Decision rule for 14 vs 15:* First establish whether others are present (Code 7). If no → Code 14 candidate. If yes → Code 15 candidate. Then ask: is the loneliness signal strong enough to warrant an interpretive code at all? If the image is ambiguous or the loneliness reading requires significant inference, code both 0.

## D. AI Default Tropes

### Code 16: Rain or grey weather
Rain, overcast skies, fog, or grey/gloomy weather is visually present.

### Code 17: Stereotyped figure — elderly person
The subject is visibly elderly (grey hair, aged features, older presentation).

### Code 18: Stereotyped setting — park bench
The subject is seated on a park bench or equivalent isolated outdoor seat.

### Code 19: Exaggerated or theatrical sadness
The subject's emotional expression is exaggerated — visibly crying, dramatically sad, or stylised in a way that overstates the emotional state beyond naturalistic depiction.

### Code 20: Racially or demographically homogeneous crowd
Where others are present, they are visually homogeneous in a way that visually marks the subject as different or out of place. Code 1 only when the crowd's homogeneity is unambiguous from visually apparent features — such as clothing, clearly depicted group context, or hair — and the subject is visibly differentiated from them. Do not infer ethnicity or identity beyond what is directly and unambiguously depicted in the image. When identity markers are ambiguous or require inference, code 0. If in doubt, code 0.

---

## E. Image–Prompt Adequacy

### Code 21: Image depicts a plausible everyday scene
The image shows a realistic, naturalistic scene consistent with everyday life — not fantastical, abstract, or surreal.

### Code 22: Image appears to match the social scenario in the prompt
Based on what is visible, the image appears to have captured the general social situation the prompt described (e.g. a group setting, a specific location type, a relational dynamic). Code 1 if a reasonable match; code 0 if the image clearly diverged from the intended scenario.

### Code 23: Image reproduces a stereotyped representation of loneliness
The image relies on one or more widely recognised visual shorthand for loneliness (physical isolation, darkness, rain, theatrical sadness, park bench, elderly figure) rather than a more nuanced or relational depiction.
